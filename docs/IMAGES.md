# Site imagery

All artwork in `public/images`, `public/icons`, and the favicons is generated by
`npm run images` (`scripts/generate-images.mjs`) from SVG definitions, so it is
reproducible and carries no licensing risk. Each hero ships as WebP + JPEG at
1600px and 960px widths; the OG card is 1200x630.

| File | Used on |
|---|---|
| `hero-stonebridge` | Home, Homes for Sale, Living Here |
| `stonebridge-village` | Home (figure), Neighborhoods, Stonebridge Las Vegas |
| `stonebridge-park` | Stonebridge Park, Living Here (figure) |
| `heritage-clubhouse` | Heritage at Stonebridge |
| `floor-plans` | Floor Plans |
| `prices` | Prices |
| `og-stonebridge-las-vegas-homes.png` | Open Graph / Twitter card, every page |
| `logo.svg`, `logo-light.svg`, `logo.png` | Header, footer, schema |
